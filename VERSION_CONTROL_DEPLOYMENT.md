# Predictive Maintenance MLOps - Version Control & Deployment Guide

## 📋 Overview

This document describes the version control setup using **Git** for code and **DVC** for data/models, plus deployment configurations.

---

## 🔧 Version Control Setup

### Git Repository Structure
```
MLops/
├── .git/                      # Git repository
├── .gitignore                 # Git ignore patterns
├── .dvc/                      # DVC configuration
│   ├── config                 # DVC settings
│   ├── .gitignore            # DVC internal ignores
│   └── cache/                # DVC cache (not in Git)
│
├── data/
│   ├── raw.dvc               # DVC tracking file for raw data
│   └── .gitignore            # Generated by DVC
│
├── models.dvc                # DVC tracking file for models
│
└── [all code files]          # Tracked by Git
```

### What's Tracked Where

**Git Tracks:**
- ✅ Source code (`.py`, `.ipynb`)
- ✅ Documentation (`.md`)
- ✅ Configuration files (`.yaml`, `.yml`)
- ✅ DVC tracking files (`.dvc`)
- ✅ Requirements (`requirements.txt`)
- ✅ Airflow DAGs
- ✅ Dockerfiles
- ❌ Data files (too large)
- ❌ Model files (too large)
- ❌ Virtual environments
- ❌ Cache directories

**DVC Tracks:**
- ✅ Raw data files (`data/raw/`)
- ✅ Processed data files (`data/processed/`)
- ✅ Trained models (`models/`)
- ✅ Large binary files
- ✅ Experiment artifacts
- ❌ Code (handled by Git)
- ❌ Configuration (handled by Git)

## 🚀 Git Commands

### Initial Setup
```bash

git init
```


## 📦 DVC Commands

### Already Configured
```bash
# DVC initialized with:
dvc init

# Data added to DVC:
dvc add data/raw       # Creates data/raw.dvc
dvc add models         # Creates models.dvc
```

### Daily DVC Workflow
```bash
# 1. After training new models
dvc add models

# 2. Commit DVC tracking files to Git
git add models.dvc .gitignore
git commit -m "Update models with new training run"

# 3. Push data to DVC remote storage
dvc push

# 4. Push Git changes
git push
```

### Retrieving Data/Models
```bash
# Pull data from DVC remote
dvc pull

# Or pull specific file
dvc pull data/raw.dvc
dvc pull models.dvc
```

### DVC Remote Storage Setup

#### Option 1: Local Storage (Already Active)
```bash
# Current setup (local cache)
# Data stored in: .dvc/cache/
```

#### Option 2: Cloud Storage (Recommended for Production)

**AWS S3:**
```bash
# Configure S3 remote
dvc remote add -d myremote s3://mybucket/dvcstore

# Set AWS credentials (in .dvc/config.local - not tracked)
dvc remote modify myremote access_key_id 'YOUR_KEY'
dvc remote modify myremote secret_access_key 'YOUR_SECRET'

# Or use AWS CLI credentials
dvc remote modify myremote credentialpath ~/.aws/credentials
```

**Google Cloud Storage:**
```bash
# Configure GCS remote
dvc remote add -d myremote gs://mybucket/dvcstore

# Set credentials
export GOOGLE_APPLICATION_CREDENTIALS=/path/to/credentials.json
```

**Azure Blob Storage:**
```bash
# Configure Azure remote
dvc remote add -d myremote azure://mycontainer/path

# Set credentials
dvc remote modify myremote account_name 'myaccount'
dvc remote modify myremote account_key 'mykey'
```

**After configuring remote:**
```bash
# Push data to remote storage
dvc push

# Pull data from remote storage
dvc pull
```

## 🐳 Docker Deployment

### Dockerfile
```dockerfile
FROM python:3.13-slim

WORKDIR /app

# Install system dependencies
RUN apt-get update && apt-get install -y \
    git \
    && rm -rf /var/lib/apt/lists/*

# Copy requirements
COPY requirements.txt .

# Install Python dependencies
RUN pip install --no-cache-dir -r requirements.txt

# Copy application code
COPY . .

# Pull DVC tracked files
RUN dvc pull

# Expose port for API
EXPOSE 8000

# Run the application
CMD ["uvicorn", "src.deployment.api:app", "--host", "0.0.0.0", "--port", "8000"]
```

### Docker Commands
```bash
# Build image
docker build -t mlops-predictive-maintenance:latest .

# Run container
docker run -d -p 8000:8000 --name mlops-app mlops-predictive-maintenance:latest

# View logs
docker logs mlops-app

# Stop container
docker stop mlops-app

# Remove container
docker rm mlops-app
```

### docker-compose.yml
```yaml
version: '3.8'

services:
  app:
    build: .
    ports:
      - "8000:8000"
    environment:
      - MLFLOW_TRACKING_URI=http://mlflow:5000
    volumes:
      - ./models:/app/models
      - ./data:/app/data
    depends_on:
      - mlflow

  mlflow:
    image: ghcr.io/mlflow/mlflow:v2.9.2
    ports:
      - "5000:5000"
    command: mlflow server --host 0.0.0.0 --port 5000
    volumes:
      - mlruns:/mlflow/mlruns

  airflow:
    image: apache/airflow:2.7.3
    ports:
      - "8080:8080"
    environment:
      - AIRFLOW__CORE__EXECUTOR=LocalExecutor
    volumes:
      - ./airflow/dags:/opt/airflow/dags

volumes:
  mlruns:
```

### Docker Compose Commands
```bash
# Start all services
docker-compose up -d

# View logs
docker-compose logs -f

# Stop all services
docker-compose down

# Rebuild and restart
docker-compose up -d --build
```

## ☁️ Cloud Deployment Options

### AWS Deployment

**Using AWS SageMaker:**
```python
# sagemaker_deploy.py
import sagemaker
from sagemaker.sklearn import SKLearnModel

# Load model from DVC
model = SKLearnModel(
    model_data='s3://bucket/models/production_model.pkl',
    role='SageMakerRole',
    entry_point='inference.py',
    framework_version='1.0-1'
)

# Deploy
predictor = model.deploy(
    initial_instance_count=1,
    instance_type='ml.m5.large'
)
```

**Using AWS ECS/Fargate:**
```bash
# Build and push to ECR
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin <account>.dkr.ecr.us-east-1.amazonaws.com

docker tag mlops-predictive-maintenance:latest <account>.dkr.ecr.us-east-1.amazonaws.com/mlops:latest

docker push <account>.dkr.ecr.us-east-1.amazonaws.com/mlops:latest

aws ecs create-service --cluster mlops-cluster --service-name mlops-service --task-definition mlops-task --desired-count 2
```

## 📊 CI/CD Pipeline Example

### GitHub Actions Workflow

Create `.github/workflows/ml-pipeline.yml`:

```yaml
name: ML Pipeline

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  test:
    runs-on: ubuntu-latest
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.13'
    
    - name: Install dependencies
      run: |
        pip install -r requirements.txt
        pip install pytest
    
    - name: Run tests
      run: pytest tests/
    
    - name: Pull DVC data
      run: |
        dvc remote add -d myremote s3://mybucket/dvcstore
        dvc pull
      env:
        AWS_ACCESS_KEY_ID: ${{ secrets.AWS_ACCESS_KEY_ID }}
        AWS_SECRET_ACCESS_KEY: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
    
    - name: Train models
      run: python mlflow_advanced.py
    
    - name: Update DVC
      run: |
        dvc add models
        dvc push
      env:
        AWS_ACCESS_KEY_ID: ${{ secrets.AWS_ACCESS_KEY_ID }}
        AWS_SECRET_ACCESS_KEY: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
  
  deploy:
    needs: test
    runs-on: ubuntu-latest
    if: github.ref == 'refs/heads/main'
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Build Docker image
      run: docker build -t mlops-app:${{ github.sha }} .
    
    - name: Push to registry
      run: |
        echo ${{ secrets.DOCKER_PASSWORD }} | docker login -u ${{ secrets.DOCKER_USERNAME }} --password-stdin
        docker push mlops-app:${{ github.sha }}
    
    - name: Deploy to production
      run: |
        # Deploy commands here
        echo "Deploying to production..."
```

## 🔄 DVC Pipeline (Advanced)

### dvc.yaml
```yaml
stages:
  data_collection:
    cmd: python src/data_collection/iot_simulator.py --samples 5000
    deps:
      - src/data_collection/iot_simulator.py
    outs:
      - data/raw/

  preprocess:
    cmd: python src/preprocessing/data_cleaner.py
    deps:
      - data/raw/
      - src/preprocessing/data_cleaner.py
    outs:
      - data/processed/

  train:
    cmd: python mlflow_advanced.py
    deps:
      - data/processed/
      - mlflow_advanced.py
    outs:
      - models/
    metrics:
      - mlflow_metrics.json:
          cache: false

  evaluate:
    cmd: python model_comparison.py
    deps:
      - models/
      - model_comparison.py
    outs:
      - model_comparison_dashboard.png
      - model_selection_recommendations.json
```

### Run DVC Pipeline
```bash
# Run entire pipeline
dvc repro

# Run specific stage
dvc repro train

# Visualize pipeline
dvc dag
```

## 🆘 Troubleshooting

### DVC Issues
```bash
# DVC cache corrupted
dvc cache clean
dvc pull

# DVC remote not accessible
dvc remote list
dvc remote modify myremote url <new-url>

# Force push to DVC
dvc push --force
```

### Git Issues
```bash
# Undo last commit (keep changes)
git reset --soft HEAD~1

# Discard all local changes
git reset --hard HEAD

# Resolve merge conflicts
git merge --abort  # Cancel merge
# Or manually resolve and:
git add .
git commit
```

### Docker Issues
```bash
# Clean up Docker
docker system prune -a

# View container logs
docker logs <container-id>

# Enter running container
docker exec -it <container-id> bash
```
